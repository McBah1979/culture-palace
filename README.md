# Станично-Луганский дворец культуры

Сайт с серверной панелью администратора. Публичные страницы доступны всем, настройки сохраняются в `site-content.json` через GitHub Contents API. Пароль и токен не хранятся в репозитории.

## Запуск локально

Требуется Node.js 20+ без дополнительных пакетов. Укажите `ADMIN_LOGIN`, `ADMIN_PASSWORD`, `SESSION_SECRET` и `CONTENT_FILE` в окружении, затем выполните `node server.js`. Для проверки запустите `node --test tests/server.test.js`. Вместо `ADMIN_PASSWORD` поддерживается `ADMIN_PASSWORD_HASH` формата `<32 шестнадцатеричных символа соли>:<128 символов результата scrypt(password, salt, 64)>`.

## Render

`render.yaml` описывает новый Node web service `stanichno-luganskiy-dk-app`. Существующий статический сервис нужно заменить серверным после проверки нового адреса; статический сервис не может проверить пароль или сохранить настройки.

При создании Blueprint в Render укажите секретные переменные `ADMIN_PASSWORD` и `CONTENT_GITHUB_TOKEN`. Логин `admin` задан в `render.yaml` переменной `ADMIN_LOGIN` (на уже созданном сервисе проверьте значение в Environment). Для `CONTENT_GITHUB_TOKEN` создайте **отдельный fine-grained GitHub token** с доступом только к репозиторию `McBah1979/culture-palace` и правом **Contents: Read and write**. Render автоматически создаст `SESSION_SECRET`; остальные настройки перечислены в `render.yaml`. Не добавляйте токен и пароль в файлы репозитория.

После запуска откройте сайт и нажмите «Администратору». В редакторе доступны тексты существующих блоков, ссылки, цвета и фотографии. Выберите изображение JPG, PNG или WebP до 2 МБ в секции «Фото»; сервер загрузит его в `images/` репозитория. Затем нажмите «Сохранить изменения», чтобы привязать его к выбранному месту. Сохранение меняет файл `site-content.json` в GitHub; обновление публичной версии может занять до 30 секунд. Не загружайте неподтверждённые фотографии коллективов.
